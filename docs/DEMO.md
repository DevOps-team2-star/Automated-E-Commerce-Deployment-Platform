# Demo runbook (7 Dec 2026, ~20 minutes)

## Before the demo (T-60 min)

1. Docker Desktop running; in WSL Ubuntu: `./scripts/local-k8s-up.sh && ./jenkins/run-jenkins.sh`
2. Jenkins http://localhost:8090 -> run **infra-apply** (about 15-20 min: Terraform -> Ansible -> shop-pipeline).
3. When it finishes, note the shop URL printed at the end (also in Jenkins: `$JENKINS_HOME/aws/shop_url`).
4. Get the AWS kubeconfig into WSL for live kubectl:
   `docker cp jenkins:/var/jenkins_home/kube/aws.yaml ~/.kube/aws.yaml && export KUBECONFIG=~/.kube/aws.yaml`
5. Grafana on AWS: `./monitoring/port-forward.sh` (uses the current KUBECONFIG) -> http://localhost:3000
   (password: `kubectl -n monitoring get secret grafana-admin -o jsonpath='{.data.admin-password}' | base64 -d`).
6. Open tabs: GitHub repo (PR list), Jenkins, shop URL, Grafana "Shop - Golden Signals" and "Shop - Scaling",
   Prometheus Alerts, AWS console (EC2, RDS, S3, Load Balancers).
7. Start light background traffic: `hey -z 30m -c 2 -q 2 <shop-url>/` (keeps dashboards alive).

## Script

| # | Min | Show | Say |
|---|---|---|---|
| 1 | 2 | README architecture + docs/PLAN.md diagram | Downtime and manual deploys are the problem; this pipeline removes both. |
| 2 | 1 | GitHub: branches `feat/part-0..9`, merged PRs | One branch and PR per deliverable; `main` is always deployable. |
| 3 | 3 | `terraform/` modules, Jenkins infra-apply log, AWS console | VPC, 2 EC2, RDS in private subnets, S3 images, ALB. Remote state in S3 with locking. `agent_count` / `enable_rds` are variables. |
| 4 | 2 | `ansible/site.yml`, roles, second run `changed=0` | Inventory and variables are generated by Terraform; the playbook is idempotent. |
| 5 | 3 | `kubectl get nodes,pods,hpa -n shop`; shop via ALB; buy something | ALB -> Nginx (NodePort 30080) -> web/search/payment; orders land in RDS; images come from S3. |
| 6 | 3 | Edit `STORE_TITLE` in `app/web/app.py`, push; Jenkins stage view | Build once with the Git SHA tag, compose smoke test, push, rolling deploy, smoke test, 5xx gate. Title changes with zero errors. |
| 7 | 2 | `./scripts/hpa-demo.sh <shop-url> 180` + Scaling dashboard | CPU passes 60% of the request -> HPA adds pods up to 6, removes them after the load. |
| 8 | 3 | Commit `FAIL_READY: "true"` in `k8s/base/web.yaml`, push | New pods never get Ready, old pods keep serving, Verify fails, Jenkins runs `rollout undo`. Then `git revert`. Also show the one-click **shop-rollback** job. |
| 9 | 1 | `./monitoring/alert-demo.sh <shop-url>` (or scale payment to 0) | ShopHighErrorRate goes Pending -> Firing, then resolves. |
| 10 | 1 | Jenkins **infra-destroy** (approve) | Everything except the state bucket is removed; it also runs every night at 23:00 as a safety net. |
